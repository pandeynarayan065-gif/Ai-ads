# @velvetengine "Every light and the prompt for it" (Seedance reel) — reverse-engineered lighting library

**Source:** reel Narayan uploaded 17 Nov 2026 (#aifilm #seedance #cinematography #filmlighting #velvetengine), 55 s,
960x720. One character (a teddy-bear-headed man in a teal suit and red ruffled shirt, on an orange chair on a
checkerboard floor) relit 14 ways, each card naming the light and the films it is "for". Their prompts are behind
"link in bio" (not in the video), so the blocks below are **our** reverse-engineered wording from the frames.

**Why it works:** one locked subject, set and framing; only the light changes, so each card teaches one variable.
Each light is named by its film-craft term plus a film it evokes.

## Adopt / Avoid
- **Adopt:** name lights by craft term + one film reference + one source/side/quality/colour; keep subject and frame
  fixed when testing a look. The Red (Suspiria) and Low key setups match the dark-red "Batman edit" grade.
- **Avoid:** text cards from the model (titles are post). The bear-head character is theirs; don't reuse it.
