# Copywriting Frameworks & Angles

## Frameworks

- **AIDA** — Attention, Interest, Desire, Action. Good default for longer primary text.
- **PAS** — Problem, Agitate, Solution. Strong for pain-driven offers.
- **BAB** — Before, After, Bridge. Paint the current state, the better state, then the product as the bridge.
- **FAB** — Features, Advantages, Benefits. Useful for technical / B2B products.
- **4U** — Useful, Urgent, Unique, Ultra-specific. A checklist for headlines.
- **Hook → Value → CTA** — Short-form video / TikTok / Reels script shape.

## Angles (use a different one per variation)

| Angle | Lead with |
|---|---|
| Pain | The problem the audience feels right now |
| Benefit | The outcome they get |
| Social proof | Reviews, customer counts, logos — only if provided in the brand file |
| Urgency / scarcity | Deadlines, limited stock — only if real |
| Curiosity | An open loop or surprising fact |
| Objection | The #1 reason people don't buy, answered |
| Comparison | Versus the old way / the alternative (no naming competitors unless allowed) |
| Identity | "For people who..." — who it's for, framed positively |
| Offer | The deal itself, stated plainly |

## Headline checklist

- Specific beats clever. Numbers, timeframes and concrete nouns help.
- One idea per headline.
- Speak to "you", not "we".
- Front-load the important words (truncation cuts the end).
