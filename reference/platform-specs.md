# Platform Text Specs

Character limits include spaces. Platforms change these — verify against official docs for
anything high-stakes. "Rec." = recommended length before text gets truncated.

| | Headline | ~40 rec. | |
| | Description | ~30 rec. | |

## Creative specs (for visual concepts)

- Meta / Instagram feed: 1:1 (1080×1080) or 4:5 (1080×1350); Stories/Reels 9:16 (1080×1920)
- TikTok: 9:16 (1080×1920), hook in the first 2 seconds, keep key text out of the bottom ~20%
- LinkedIn single image: 1.91:1 (1200×627) or 1:1 (1200×1200)
- Google Display: landscape 1.91:1 (1200×628), square 1:1 (1200×1200)
